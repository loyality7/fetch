Why does my coroutine keep running after cancel?

I call cancel on the job but the loop inside keeps printing. I expected it to stop immediately. The loop is a plain while that does some arithmetic and never calls any suspending function inside the body.

while (true) { compute() }

Cancellation is cooperative. A coroutine is only cancelled at a suspension point, so a tight loop that never suspends will run to completion. Call ensureActive inside the loop, or use yield, and the cancellation will take effect.

while (isActive) { compute() }
