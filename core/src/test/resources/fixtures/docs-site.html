Cancellation

Every call in the SDK is cancellable. Cancelling the calling scope propagates downwards through the request, the parser and any pooled resource, so no work continues after the caller has stopped caring about the result.

Cancelling a request

val job = scope.launch { client.fetch(url) }
job.cancel()

Cancellation is cooperative. A blocking call that never yields cannot be interrupted, which is why every long operation in the SDK either suspends or checks for cancellation between chunks.

Timeouts

A timeout is cancellation with a deadline attached. Prefer a timeout at the outermost call rather than one per stage, so the total budget stays predictable.

SettingDefault
connectTimeout10s
readTimeout20s
